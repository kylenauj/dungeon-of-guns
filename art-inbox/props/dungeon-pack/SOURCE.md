# Dungeon prop pack ("Models Final")

From `Models.rar`, uploaded by the owner on 2026-10-21 (branch
`claude/jolly-hamilton-gij2j5`). Free on itch.io, per the owner; the archive
had no licence file. The pack's own texture atlases were not included, so the
game shades these by material itself (tools/kit.js, js/render/kitmodels.js).

Only the models the game uses are copied here: Stocks, Guillotine, X Stocks,
Shackle Plank, Trap (a spiked board), Weapon Rack, Cage (a gallows cage).
